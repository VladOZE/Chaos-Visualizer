# Chaos Visualizer

Приложение для моделирования и визуализации хаотических динамических систем с графическим интерфейсом на PyQt5.

## Описание

Chaos Visualizer — это инструмент для численного моделирования и интерактивной визуализации классических хаотических систем, таких как система Лоренца и аттрактор Рёсслера. Приложение позволяет исследовать поведение этих систем при различных параметрах и начальных условиях, визуализировать результаты в 2D и 3D, а также экспортировать данные и графики.

## Требования

- Python >= 3.12
- Все зависимости указаны в `requirements.txt`

## Установка

1. Клонируйте репозиторий или скачайте проект:
```bash
git clone https://github.com/VladOZE/Chaos-Visualizer.git
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
   - Windows:
     ```bash
     venv\Scripts\activate
     ```
   - Linux/Mac:
     ```bash
     source venv/bin/activate
     ```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск приложения

Запустите главный файл:
```bash
python src/main.py
```

Или из корневой директории проекта:
```bash
cd src
python main.py
```

## Использование

### Основные операции

1. **Выбор системы**: Выберите систему из выпадающего списка (Лоренц или Рёсслер)

2. **Настройка параметров**: Измените параметры системы с помощью ползунков или полей ввода

3. **Установка начальных условий**: Задайте начальные значения координат (x₀, y₀, z₀)

4. **Запуск моделирования**: Нажмите кнопку "Запустить моделирование"

5. **Просмотр результатов**: Результаты отображаются в виде графиков в интерфейсе

6. **Экспорт**: Сохраните траектории и графики в различных форматах

### Примеры параметров

**Система Лоренца (классический хаотический режим):**
- σ (sigma) = 10.0
- ρ (rho) = 28.0
- β (beta) = 8/3 ≈ 2.67

**Аттрактор Рёсслера:**
- a = 0.1
- b = 0.1
- c = 14.0

## Математические модели

### Система Лоренца

Система дифференциальных уравнений:
```
dx/dt = σ(y - x)
dy/dt = x(ρ - z) - y
dz/dt = xy - βz
```

где:
- σ (sigma) — число Прандтля
- ρ (rho) — число Рэлея
- β (beta) — параметр геометрии

### Аттрактор Рёсслера

Система дифференциальных уравнений:
```
dx/dt = -y - z
dy/dt = x + ay
dz/dt = b + z(x - c)
```

где a, b, c — параметры системы.

## Логирование

Приложение ведёт логи в файл `logs/app.log`. Уровень логирования можно настроить в `src/logger.py`.

## Конфигурация

Параметры по умолчанию для систем и интегрирования можно изменить в файле `config/default_params.json`.

## Разработка

### Добавление новой системы

1. Создайте новый класс, наследующийся от `DynamicalSystem` в `src/models/`
2. Реализуйте методы:
   - `compute_derivatives()` — вычисление производных
   - `set_parameters()` — установка параметров с валидацией
   - `get_info()` — информация о системе
3. Добавьте систему в интерфейс в `src/ui/main_window.py`
